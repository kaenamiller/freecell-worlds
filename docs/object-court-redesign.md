# Object and creature court redesign

The final user selections retain the previous humanoid courts for Zen Garden, Hangar X, The Velvet Moth, Arctic Station and Risograph Royalty. All other proposed object/creature sets are approved. There are 21 object/creature themes and five retained humanoid themes in this review.

Radio Outpost uses headphones for Jack, the instrument panel for Queen, and the radio dish for King. Midnight Broadcast uses the microphone for Jack, the walnut radio console for Queen, and the test-pattern TV for King.

All generated artwork uses Nano Banana 2.1 (`gemini-nano-banana-2.1`) through the Gemini scripts. Approved object sets use full-subject fitting inside each half of the double-ended card. Retained humanoid themes use their original portrait crop.
